## How it works

A static site built with vanilla HTML, CSS, and JavaScript, hosted on GitHub Pages. All content lives in `data/*.json` and is rendered by `assets/js/main.js`, so updating the site means editing those JSON files.

To preview locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
